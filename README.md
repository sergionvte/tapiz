# Perforado

Web app para crear fondos de pantalla de patrón a la resolución exacta de tu pantalla.

- Detecta las medidas de la pantalla (píxeles reales × densidad) o elige un modelo de iPhone, iPad, Android, Mac o monitor.
- Tema oscuro / claro, color base libre y color del patrón automático o manual.
- 8 patrones: perforado, rejilla, panal, rombos, cruces, rayas, cuadrícula y fibra.
- Escala, grosor, degradado, grano y desenfoque ajustables.
- Exporta PNG (en el móvil abre el menú de compartir para guardarlo en Fotos).

Todo se genera en el navegador con Canvas; no hay servidor ni dependencias.
